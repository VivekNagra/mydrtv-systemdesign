# Funktionelle krav
- Opret/vis programmer (Catalogue)
- Seed default-programmer (admin endpoint)
- Registrér/log ind brugere og få JWT (Identity)
- Opret ratings/reviews og se gennemsnit (Ratings)
- Søg programmer inkl. rating-data (Search)
- Hent simple anbefalinger baseret på genre/minRating (Recommendations)
